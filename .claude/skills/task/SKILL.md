# ניהול משימות — `product-backlog/TASKS.md`

הארגומנט: `$ARGUMENTS`. אם ריק — הצג `npm run tasks` (מה ב-Now + הבאה בתור) והצע את הצעד הבא.

**עיקרון:** `TASKS.md` הוא אינדקס של סדר וסטטוס, לא מקום לפרטים. פרטים נשארים באפיון הפיצ'ר / `BUGS.md` / `IDEAS.md`. עורכים את
הקובץ ישירות (Edit) — אין CLI להוספה. **אחרי כל עריכה מריצים `npm run tasks:check`** ומתקנים עד שהוא ירוק. פורמט שורה וכללים: בראש `TASKS.md`.

## פעולות

**add — משימה חדשה.**
1. סווג: `feature` (תכולה חדשה), `bug`, `chore` (תחזוקה/אימות/פריסה), `idea` (גולמי, בלי החלטות).
2. מזהה פנוי: `npm run tasks -- id <F|T|I>`. באג חדש → קודם רשומה ב-`BUGS.md` לפי skill `fix-bug` §4 (מספר = הגבוה אי פעם + 1), ואז שורה כאן.
3. הערך גודל (S/M/L, או `?` אם אין בסיס) והוסף: מוכן → `Next` במקום המתאים לעדיפות; חסום/לא ברור/רעיון → `Later`.
4. פיצ'ר שצריך אפיון: שורה ב-`Later` עם `⛔ ממתין לאפיון` ולהפעיל `dev-team:product-manager` — לא מאפיינים כאן. רעיון בשורה-שתיים: גם ב-`IDEAS.md` אם יש פרטים.
5. אם המשתמש נתן תיאור אחד לכמה דברים — פצל לשורה לכל דבר. אל תמציא עדיפות: ברירת מחדל סוף `Next`, ואמור היכן שמת.

**next — קח את הבאה.** `npm run tasks` → המשימה הראשונה הלא-חסומה ב-`Next`. אם `Now` כבר מלא (2) — עצור ושאל מה לסגור/לדחות.
העבר אותה ל-`Now`, קרא את הקובץ המקושר, והתחל לעבוד לפי הזרימה הרגילה (פיצ'ר → `dev-team:tech-lead`; באג → skill `fix-bug`; chore → ישירות).

**done <ID> — סיום.** לפני שמסמנים: קריטריון הסיום של סוג המשימה (פיצ'ר: Backend+Frontend+בדיקות+הטמעה כפי שב-`TEAM.md`; באג: `fix-bug`).
העבר ל-`Done`, החלף ל-`[x]`. פיצ'ר: שורה אחת נשארת תמיד. אם נשארו פריטי המשך (אימות ידני, פריסה) — **פתח עבורם `chore`**, אל תשאיר אותם בפרוזה בלבד.
באג שתוקן: למחוק מ-`BUGS.md` (הכלל הקבוע) ולהעביר/למחוק את שורתו כאן. עדכן גם את טבלת הסטטוס ב-`README.md` של התיקייה אם זה פיצ'ר.

**block / unblock.** הוסף `⛔ <סיבה קצרה וקונקרטית>` בסוף השורה (מי/מה צריך להתרחש). פתרו → מחק את ה-`⛔` ואם צריך הזז ל-`Next`.

**move <ID> <section>.** הזזת שורה = שינוי עדיפות. `Now` מקסימום 2. בתוך `Next` — הסדר הוא העדיפות.

**list.** `npm run tasks -- list`. דווח בקצרה: מה ב-Now, 3 הבאות, וכמה חסומות ולמה.

**הממשק (`npm run tasks:ui`)** עורך את אותו קובץ בזמן שאתה עובד: לפני עריכה ידנית קרא את הקובץ מחדש (Read), כי נוה אולי גרר שורות. הממשק מזהה שינוי חיצוני ומרענן את עצמו (409), אז עריכה שלך לא תיפגע.

## מה לא עושים
- לא מעתיקים תוכן אפיון/שחזור לתוך `TASKS.md` — רק כותרת + קישור.
- לא מוסיפים שדות (עדיפות, אחראי, תאריך יעד, סטטוס "בבדיקה"…) — הפורמט נועל את זה בכוונה.
- לא מוחקים פיצ'ר מ-`Done`, ולא מסדרים מחדש `Next` בלי שהתבקשת — הסדר הוא החלטה של נוה.
- לא עושים `commit` אלא אם התבקשת.
