# משימות (TASKS)

**רשימה אחת של כל העבודה שנשארה בפרויקט — פיצ'רים, באגים, תחזוקה ורעיונות — בסדר עדיפות.** אין ספרינטים ואין board:
יש רק "מה עכשיו", "מה הבא" ו"מה לא עכשיו". פותחים את הקובץ ורואים מיד מה הצעד הבא.

**הקובץ הזה הוא האינדקס (סדר + סטטוס), לא מקום לפרטים.** הפרטים נשארים איפה שהם היו:
אפיון פיצ'ר ב-`NN-*.md`, שחזור באג ב-`BUGS.md`, פירוט רעיון ב-`IDEAS.md`. כל שורה כאן מצביעה אליהם.
אם יש סתירה בין שורה כאן לבין הקובץ המפורט — הקובץ המפורט נכון, ומתקנים את השורה.

## איך קוראים שורה

```
- [ ] F-13 · feature · M · עריכה ומחיקה של הערה → [spec](./13-comment-edit-delete.md) ⛔ למה חסום
       │      │         │   │                        │                                      └ אופציונלי: חסום (מדלגים עליו)
       │      │         │   │                        └ אופציונלי: קישור לפירוט
       │      │         │   └ כותרת קצרה
       │      │         └ גודל: S (שעה-שעתיים) · M (חצי יום-יום) · L (כמה ימים) · ? (לא הוערך)
       │      └ סוג: feature | bug | chore | idea
       └ מזהה: F-NN (מספר קובץ הפיצ'ר) · BUG-NN (כמו ב-BUGS.md) · T-NN (תחזוקה) · I-NN (רעיון)
```

**כללים:**
- **הסדר בתוך "Next" הוא העדיפות.** העליון ראשון. אין שדה עדיפות — מזיזים שורה למעלה/למטה.
- **"Now" — מקסימום 2 משימות.** מה שעובדים עליו בפועל. הסקריפט נכשל אם יש יותר.
- **שורה עם `⛔`** חסומה (תלויה בהחלטה / במשימה אחרת / במכשיר) — `npm run tasks -- next` מדלג עליה. כשהחסימה נפתרת מוחקים את ה-`⛔`.
- **הושלם** = מעבירים ל-"Done" ומסמנים `[x]`. פיצ'ר נשאר שם לתמיד (שורה אחת, בלי עלות). באג/תחזוקה שהושלמו אפשר למחוק אחרי כמה ימים.
- **באג שתוקן** = גם נמחק מ-`BUGS.md` (הכלל הקיים ב-`CLAUDE.md`) וגם שורתו עוברת כאן ל-"Done" (או נמחקת).
- **משימה חדשה** נכנסת ל-"Next" (אם מוכנה) או ל-"Later" (אם חסומה / לא ברורה / רעיון). מזהה פנוי: `npm run tasks -- id T`.
- **ממשק:** `npm run tasks:ui` ← http://127.0.0.1:4777. גרירה לשינוי עדיפות/העברה בין סעיפים, סימון Done, חסימה, גודל והוספת תחזוקה/רעיון.
  הוא עורך את הקובץ הזה ישירות, ומציג התקדמות של כל פיצ'ר מתוך ה-checklist (`- [x]`) בקובץ האפיון שלו. פיצ'ר/באג חדשים, וסגירת פיצ'ר/באג — דרך Claude (`/task`), כי הם דורשים אפיון / `BUGS.md` / הטמעה.
- **בדיקת עקביות:** `npm run tasks:check` — מוודא פורמט, מזהים ייחודיים, קישורים תקינים, כל קובץ פיצ'ר מיוצג,
  וכל באג פתוח ב-`BUGS.md` מיוצג כאן (ולהפך). הסדר/העדיפויות הראשוניים כאן הם הצעה — נוה מסדר מחדש כרצונו.
